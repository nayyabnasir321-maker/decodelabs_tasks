# Caesar Cipher - Encryption & Decryption Tool

This is Project 2 of my DecodeLabs Cyber Security Internship. 
It implements the Caesar Cipher — a classic substitution cipher 
that encrypts and decrypts text using a shift key.

## Features
- Encrypts text using a user-defined shift key
- Decrypts text back to original message
- Handles uppercase and lowercase letters
- Preserves spaces, numbers, and punctuation

## How to Run
1. Clone this repository
2. Run the script using: `python caesar_cipher.py`
3. Enter your message when prompted
4. Enter a shift key (any number)
5. View the encrypted and decrypted output

## Example

Enter your message: Hello World
Enter shift key (number): 3

Original Message : Hello World
Encrypted Message: Khoor Zruog
Decrypted Message: Hello World
